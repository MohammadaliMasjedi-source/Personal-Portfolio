See the SQL behind this report
SELECT w.title, COUNT(e.id) AS enrolments
FROM workshops w
LEFT JOIN enrolments e ON e.workshop_id = w.id
GROUP BY w.id, w.title
ORDER BY w.id;

Why COUNT(e.id), rather than COUNT(*)? Try the exercise in the learner guide.
